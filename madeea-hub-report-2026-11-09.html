What was wrong with the Delegation Coach

The app (originally built in Lovable) was run screen by screen on desktop and phone, and its code checked against the database and the live AI.

ProblemNow
The AI pointed at an old n8n address that no longer exists, so nobody could finish an assessment or make a plan.Uses MadeEA's live n8n, and reads its answers in the shape it actually sends.
When the AI failed, people were stuck with no way forward."Continue without AI" and "Build plan anyway"; plans still save with the person's own answers.
Plans failed to save without a deadline, "Edit" made a second copy, and people's own success criteria and risks were overwritten.Saves every time, edits the same plan, and keeps the person's answers first.
Check-ins were saved but never shown, and could not be marked done.A check-in series per plan, upcoming check-ins on the dashboard, Mark done with notes.
The dashboard showed a made-up "Level 3, 75% to Level 4".Real counts only; draft plans appear with "Finish setup".
"Forgot password" led nowhere.A "Set a new password" screen.
Much of the text was dark navy on a dark background, progress bars looked backwards, and plan pages ran off the side of a phone.Readable colours, correct progress bars, nothing scrolls sideways.
Dates showed as raw timestamps; the PDF and calendar exports were faulty.Normal dates everywhere, safe PDF export, a calendar file that imports properly.

The AI webhook now needs a secret key

The Delegation Coach and the Hub's client portal Delegate tab both use the same n8n webhook. It was open: anyone who found the address could run AI requests on MadeEA's account. Now:

  • n8n refuses any request without the secret key.
  • The Delegation Coach reaches the AI only through its own server, which first checks the person is signed in and writes the AI's instructions itself.
  • The Hub's delegation coach sends the same key.

Sign-up and password emails

Three DNS records now need adding where madeea.io is managed (a Hostinger account other than Bryan's), or madeeas.com (on Cloudflare) can be used instead.
