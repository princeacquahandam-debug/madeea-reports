The same rules for every answer

The deck's eight rules apply on every page, so people learn to trust the buttons:

  • Only real data. The Hub works out every count and total itself; Madeline only puts them into words.
  • One summary sentence first, counts first; short cards (5 rows) and panels (10 items).
  • Every row says why, with a fact ("21 days overdue", "due today").
  • Nothing changes until you press Apply, Send or Create; emails always ask to confirm.
  • Each button follows the page's filters, the selected client and your role.
  • When there is nothing, one honest line ("Nothing has gone quiet.") and no AI cost.
  • Every answer says what it read ("Based on your tasks and inbox · just now") and offers Continue in chat.
  • A click outside closes it.

Safety net: if a smaller model fails or returns an answer the Hub can't read, that request is retried once on gpt-4o, so the user sees an answer rather than an error. The fixed part of Madeline's instructions now comes first, so OpenAI bills it at its cheaper cached rate, and an identical quick action within 15 minutes reuses the answer.

5Ready to run

The switch rule, checked with real requests

The deck says to keep the larger model for any action where the smaller one isn't good enough: format 100%, facts correct 98%, median answer under 3 seconds, on 50 to 100 real requests. A script now replays real past requests through both models and gives a verdict for each action. It is best run after a week of real use (about $3 to $5 in OpenAI cost).

Done differently from the deck

  • Request correction and Message open a ready draft in Madeline, as the Hub has no direct messages between team members.
  • Check missing hours skips weekends only; the Hub has no holiday or leave records yet.
  • Client weekly report matches EOD lines to a client by name, as EOD reports don't record a client.
  • Calendar blocks and sent emails can't be undone; emails always confirm before sending.
  • Overnight batch processing for client reports (the deck's "not counted" extra) is not built yet.
